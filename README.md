# C++ Foundations — Practice Archive

A collection of introductory C++ exercises written while building programming fundamentals before college.

This repository is a learning archive: the programs are small, independent exercises rather than one integrated application. Some filenames reflect the original practice sequence and have been retained to preserve that history.

## Topics represented

- Basic input/output and arithmetic
- Conditional logic and loops
- Arrays and introductory algorithms
- Functions
- Number and pattern exercises
- Strings and vectors

## Repository layout

Most exercises currently live in the repository root. Filename prefixes provide a rough grouping (for example, `arr`, `fun`, `pat`, `vec`, and `bin`). A future cleanup can move files into topic directories after each program has been reviewed.

## Running an exercise

Compile one source file at a time with a C++ compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic path/to/program.cpp -o program
./program
```

Each file may contain its own `main()`, so compiling every source file together is not intended.
